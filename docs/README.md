# Note Scribe documentation

Note Scribe turns uploaded study material (photos and PDFs) into editable study notes and quizzes.

| Document | What it covers |
| --- | --- |
| [features.md](./features.md) | Every user-facing feature and how it behaves, including limits and failure handling |
| [architecture.md](./architecture.md) | Layers, request flows, data model, storage, AI integration, security model |
| [developer-guide.md](./developer-guide.md) | Setup, environment variables, scripts, conventions, and the checklist for adding a feature |
| [deployment.md](./deployment.md) | Hosting requirements and step-by-step deploys to Vercel, Netlify or any Node host; scheduled clean-up; free-tier limits |
| [security.md](./security.md) | Threat model, current controls, the hardening plan, and requirements for social sign-in and calendar features |
| [changelog.md](./changelog.md) | Dated record of changes and new features |

**Keep these documents current.** Any change to behaviour, data model, environment variables, scripts or architecture must be reflected here in the same change (see the checklist in [developer-guide.md](./developer-guide.md#adding-or-changing-a-feature)).
